
# 🚀 PrimeChat

PrimeChat is a real-time chat application built to provide smooth and reliable communication between users. This project focuses on real-time messaging, user handling, and a clean user experience.

## 🌐 Live Demo 
https://primechat-6nzu.onrender.com
---

## 📌 Features
- 🔐 User Authentication (Login / Signup)
- 💬 Real-time Messaging
- 🧑‍🤝‍🧑 User-to-user chat
- ⚡ Fast and responsive UI
- 📦 Organized backend structure
- 🐳 Docker support (for deployment)

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Other:** Docker  

---

## 📁 Project Structure
```
api/        → Backend APIs  
config/     → Configuration files  
includes/   → Core backend logic  
public/     → Public assets  
scripts/    → Utility scripts  
sql/        → Database files  
views/      → UI templates  
```

---

## ⚙️ Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/abishek-udhayakumar/primechat.git
```

2. Navigate to the project:
```bash
cd primechat
```

3. Import database:
- Use files inside `sql/` folder

4. Run the project using:
- Local server (XAMPP / WAMP) OR
- Docker (if configured)
